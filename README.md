manuscript:

> Olson ND, Dwarshuis N, Hansen NF, *et al.*, Zook JM. The Genome In A Bottle
> HG002 assembly-based variant benchmark set enables comprehensive benchmarking
> of small and structural variants. Submitted to *Cell Genomics* and posted to
> bioRxiv, 2026-09-22. bioRxiv DOI: *TBD*.

  [`v5-submission`](https://github.com/nate-d-olson/q100-variant-benchmark-paper/tree/v5-submission)

## Reproducing the results

1. **Set up environments** (see [Prerequisites](#prerequisites)).
2. **Obtain inputs.** Benchmark sets, references, and stratifications are
   downloaded by the workflow from pinned GIAB URLs; the Platinum Pedigree
   truth set (Fig 6) is fetched from S3 by `R/data_loading.R`. Files under
   `data/` (except `data/pangene/`) come from the data release.
3. **Run the pipeline:** `make run` (writes `results/`).
4. **SVbyEye inputs for Fig 3 / Fig S1** (outside Snakemake):

   ```bash
   mamba env create --file scripts/envs/svbyeye-prep.yaml
   mamba activate svbyeye-prep
   bash scripts/prep_svbyeye_pafs.sh GRCh38 chr8
   bash scripts/prep_svbyeye_beds.sh GRCh38
   ```

5. **Figure scripts:**

   ```bash
   Rscript scripts/make_ideogram_heatmap.R   # Fig 3, Fig S1
   ```

   Fig 4 commands are in `docs/pangene-vector-export.md`.
6. **Notebooks:** `quarto render` (Table 1, Fig 2, Fig 5, Fig 6, Table 4).

## Prerequisites

- Conda or Mamba (Snakemake 9.17 and dev tools via `environment.yaml`)
- R 4.6.1 with Bioconductor 3.23; packages restored with renv
- Quarto >= 1.10 (for notebook rendering)
- Node.js (Fig 4 pangene SVG export only)

```bash
mamba env create -f environment.yaml
mamba activate q100-smk

# R packages (from the repo root)
Rscript -e 'renv::restore()'
```

## Development commands

```bash
make dry-run   # validate DAG and inputs
make run       # run the workflow
make test      # lint + format checks + unit tests + dry-run
make test-py   # Python unit tests
make test-r    # R testthat suite

quarto render analysis/benchmarkset_characterization.qmd  # one notebook
quarto render    # full site -> _site/
quarto preview   # live preview
```

## Repository layout

```text
workflow/        Snakemake pipeline (rules, scripts, envs)
config/          Runtime config + JSON schema
R/               Shared R helpers (data loading, cache, plot themes)
analysis/        Quarto analysis notebooks
scripts/         Figure scripts and utilities (+ envs/ for non-Snakemake tools)
figures/         Manuscript figures (PDF + PNG)
  vector/        Pangene SVG/PDF exports (Fig 4)
  manual/        Hand-edited figure sources (Fig 1, Fig 4)
data/pangene/    Fig 4 input GFAs (rest of data/ is from the data release)
tables/          Manuscript value verification records
docs/            Architecture, outputs, data dictionary, troubleshooting
tests/           R (testthat) and Python (pytest) tests
resources/       Downloaded pipeline inputs (gitignored)
results/         Pipeline outputs (gitignored)
```

Pipeline entry point: `workflow/Snakefile`. Configuration:
`config/config.yaml`, validated against `config/schema/config.schema.yaml`.

Key pipeline outputs:

- `results/variant_tables/{benchmark}/variants.parquet`
- `results/genomic_context/{benchmark}/genomic_context_coverage_table.csv`
- `results/genomic_context/{benchmark}/variants_by_genomic_context.parquet`
- `results/exclusions/{benchmark}/exclusion_{impact,interactions}.csv`
- `results/exclusions/{comp_id}/old_only_summary.csv`
- `results/ref_genome_sizes/{ref}_size.tsv`
